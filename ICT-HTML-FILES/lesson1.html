What is CSS?

Cascading Style Sheets — The Presentation Language of the Web

Definition

CSS stands for Cascading Style Sheets. It describes how HTML elements are displayed on screen, paper, or in other media. CSS saves a lot of work by separating content from presentation and allows you to design beautiful, consistent web pages.

  • External stylesheets are stored in .css files.
  • Used to define styles for your web pages.
  • You should have a basic understanding of HTML or XHTML to learn CSS effectively.
```

Layers of the Webpage

  • Content: HTML
  • Presentation: CSS
  • Behavior: JavaScript

Content Layer

Defines and lays out text, images, animation, sound, and video using HTML tags. This layer focuses on clarity and meaning.

  • Text must be easy to understand and meaningful.
  • Provide alternative text for images.
  • Explain acronyms and abbreviations.
  • Ensure images are unambiguous for colorblind users.

Presentation Layer

Defines how your page appears to users. CSS ensures readability, accessibility, and consistent visual layout.

  • Ensure text can be zoomed.
  • Maintain high contrast between text and background.
  • Provide consistent navigation.
  • Group content into clear sections.

Behavior Layer

Handles user interaction using JavaScript. It ensures all functionality is available regardless of the input device and improves the user experience.

HTML vs CSS

HTML is used to create the actual content and structure of a webpage.
CSS is responsible for styling — layout, colors, fonts, and visual effects.

Benefits of Using CSS

  • Saves a lot of work by reusing one stylesheet across pages.
  • Makes web pages easier to maintain and update.
  • Adds visual appeal and improves user experience.

Capabilities of CSS

  • Make your pages easily updatable.
  • Position and layer objects on the page.
  • Create custom tags and animations.

Advantages of Using CSS

  • Save typing and development time.
  • Faster loading — only one CSS file is downloaded once.
  • Multiple stylesheets can be linked to one document for flexibility.
```
